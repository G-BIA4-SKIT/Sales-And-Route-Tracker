# Sales and Route Tracker

This project is a Python program that combines sales tracking and route comparison logic. It calculates cumulative sales progress over a workweek and also determines the fastest route based on distance and speed entered by the user.

This was a class assignment for MIS 310 at CCSU.

## Project Overview
The program includes multiple console-based tasks that focus on loops, validation, calculations, and decision-making.

The project includes:
- A cumulative sales tracker for a 5-day week
- Input validation using `try` and `except`
- Percentage-of-target calculations
- Route time calculations using distance and speed
- A comparison to determine the fastest route
